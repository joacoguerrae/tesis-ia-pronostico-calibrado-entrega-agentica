Trabajás en este repositorio. Implementá el pedido de arriba.

- Leé el README.md y seguí sus convenciones.
- Agregá tests en `tests/` para lo que implementes y corré la suite con `python -m pytest`.
- En la terminal podés usar `python`, `git` y `ls`, cada uno como comando suelto. Para editar archivos usá las herramientas de edición, no scripts de Python.
- Terminá cuando el pedido esté implementado y pasen todos los tests.
